# **App Name**: ShelfView

## Core Features:

- Add Product Form: Intuitive form for adding new products, capturing name, price, category, and optional notes.
- Product Gallery: Display of products in a visually appealing card format.
- Product Filtering & Search: Filtering and search options to quickly find products by category or name.
- Favorites Designation: Enable users to mark items as favorites.  Items may appear in a separate list of favorites, or the favorite status can just be indicated on the item.
- Edit and Delete Products: Buttons for editing and deleting products, ensuring easy inventory management.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to convey a sense of trustworthiness and stability, reminiscent of classic inventory management systems.
- Background color: Dark gray (#263238) to achieve a modern 'dark mode' aesthetic, reducing eye strain and emphasizing product cards.
- Accent color: Soft lavender (#9FA8DA), an analogous color to the primary, used for interactive elements and highlights to maintain visual harmony and subtly guide user attention.
- Clean, sans-serif fonts for readability in both light and dark modes.
- Use simple, outline-style icons to represent categories and actions, ensuring clarity without visual clutter.
- Responsive grid layout that adapts to different screen sizes, maintaining usability across devices.
